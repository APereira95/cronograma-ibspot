# cronograma-ibspot
Cronograma de asistencia a las asesorías del IB Spot 2026-27

La página está en `index.html` y no necesita instalación ni compilación.
El cronograma aún no se ha incorporado; sustituye el aviso provisional por el contenido del documento HTML.

Para publicarla:

1. En **Settings → Pages → Build and deployment → Source**, selecciona **GitHub Actions**.
2. Incorpora los cambios en `main`. El flujo **Publicar en GitHub Pages** publicará la página automáticamente; también se puede ejecutar manualmente desde **Actions** sobre `main`.
3. Visita https://apereira95.github.io/cronograma-ibspot/ una vez finalizado el despliegue.

Para actualizar la página, edita `index.html` y guarda los cambios en `main`.
